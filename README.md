# AI Limits — frontend

Static PWA dashboard showing live AI usage limits per account, fetched from a Cloudflare Worker.
Registers Web Push so an installed iPhone PWA gets "task finished" notifications.

No build step — plain HTML/CSS/ES-module JS. All paths are relative so it works under the
GitHub Pages subpath `https://jerzysukiennik.github.io/AI-dashboard/`.

## Files
- `index.html` — app shell
- `styles.css` — dark glassmorphism / neon theme
- `app.js` — fetch `/state`, render cards, live countdowns, push subscription
- `sw.js` — service worker: cache-first app shell, `push` + `notificationclick`
- `config.js` — deployment config (see below)
- `manifest.webmanifest` — PWA manifest (relative `start_url`/`scope`)
- `icons/` — generated PNG icons (192, 512, maskable 512, apple-touch 180)

## Config (`config.js`)
- `WORKER_URL` — base URL of the Cloudflare Worker. **Placeholder `__WORKER_URL__` must be
  replaced after the worker deploys.**
- `VAPID_PUBLIC_KEY` — VAPID public key for `pushManager.subscribe`.
- `SUBSCRIBE_SECRET` — Bearer token sent on `POST /subscribe` (anti-spam only).
- `EXPECTED_ACCOUNTS` — accounts to show placeholder cards for before the first sync.

## Data contract
`GET ${WORKER_URL}/state` → JSON array of:
```json
{ "account":"Claude", "plan":"Max", "session":{"used":12,"limit":45,"resetsAt":"ISO"},
  "weekly":{"used":120,"limit":900,"resetsAt":"ISO"}, "updatedAt":"ISO" }
```
Polled every 45 s and on `visibilitychange`. Cards appear dynamically per `account`.

## Notes
- iOS web push (16.4+) only works from the installed PWA. On iOS Safari before install,
  the app hides the enable button and shows a Polish install banner.
- Icons are generated by an inline PIL script; re-run it to tweak the glyph.
